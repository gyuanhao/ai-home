Vibe Coding 入门 2026：不会写代码，也能做出一个 App

发布于 2026年7月28日 · 阅读约 10 分钟 · 作者：AI家AI户

一个半开玩笑的词，长成了一种工作方式

去年年初，Andrej Karpathy（前特斯拉 AI 总监、OpenAI 联合创始人）发了条推文，半开玩笑说了句 "vibe coding"：把代码这回事忘掉，告诉 AI 你想要什么，剩下的交给它。他本来是跟程序员说的。

结果最疯的是一群完全不会写代码的人。他们用这套方法做出了真能上架的 App，有人还顺手开了公司。Collins 词典把 2025 年的年度词给了 "vibe coding"。这已经不是潮流，是一种新的造东西的方式。

如果你一直想做个小工具、却被"我不会编程"劝退，这篇就是给你看的。

vibe coding 到底是个啥

说人话版本：你打开一个网页工具，用大白话描述你要啥，AI 把它做出来。你看着不对，再说一句改哪儿，它改。来回几轮，一个能用的东西就出来了。

没有语法，没有分号，不用逛 Stack Overflow。你整个过程像在聊天，聊着聊着产出个 App。

真有人这么做成了

光说方法没意思，说几个真事：

  • Duy Thanh，零技术背景，花四周时间用 AI 工具做了个叫 Pineapple Log 的 App，提交进了苹果商店。
  • Nat Eliason 用 24 小时搭了个带登录、邮件、Stripe 付款的全栈招聘板，用的还是他从来没碰过的语言，期间还抱着刚出生的娃。
  • 还有人给当营养师的妹妹做了 CRM、食谱记录和健身计划三个应用，这是他人生第一个程序。

这些不是大厂的宣传稿。普通人，真做出来了。

工具怎么选

新手先别贪多，认准两个就够：

  • Lovable（前身叫 GPT Engineer）：浏览器里用英语描述，它把前端、后端、数据库、登录全包了。对纯新手最友好，生成的界面也好看。免费额度每天 5 次，付费 20 美元 / 月起。
  • Bolt.new（StackBlitz 出品）：同样是浏览器里生成，但它会先给你看构建计划再动手，适合快速做原型。免费每月 100 万 token，付费 25 美元 / 月起。

等你的项目长大，再认识这两个：

  • Replit：自带在线 IDE 和一键部署，最适合把做好的东西真正发上线。
  • Cursor：本质是 VS Code 套了层 AI，适合已经在写代码、想在现有项目里让 AI 帮忙的人。圈子里有句话：Lovable 做 0 到 1 的原型，Cursor 做 1 到生产的打磨。

第一步怎么迈

  1. 先用一段话把你的 App 写清楚：谁用、干啥、要哪些功能。越具体越好。"做一个健身 App" 这种话 AI 会给你一堆没用的东西；"做一个 iOS 和安卓的健身记录 App，用户能建账号、记训练、看日历和进度图" 才像样。
  2. 选工具。想上架商店用原生工具，想做网页用 Lovable 或 Bolt。
  3. 把那段话贴进去，点生成。你会拿到界面、按钮、导航、基本样式，一个真能跑的 App。
  4. 用聊天改："把标题缩小""顶部加个搜索框""按日期排序"。它立刻改。
  5. 想发布，Replit 最省事；想更可控，导出到 GitHub 配 Vercel。

新手最容易踩的五个坑

  • 提示词太模糊。"做个社交 App" 会让 AI 自己脑补一千个假设。
  • 没有项目规则文档。每次对话 AI 都重新做决定，代码慢慢就乱了。
  • 功能贪多。一次只做一个流程，别想一口气全做完。
  • 完全不看代码。东西没坏就当没事，真出问题就傻眼。
  • 没研究就开做。先看同类 App 长啥样，比闷头写提示词有用。

说点实话

我不是泼冷水，是想省你时间。AI 生成的代码，2025 年有分析说 62% 带安全漏洞，Lovable 做出来的 1645 个应用里 170 个有严重安全问题。涉及登录、付款、用户数据的，别自己手搓认证，用现成的库；API 密钥别写死在代码里；上线前用真实边界情况测一遍。个人小工具风险低，拿出来收钱的那一刻，安全审查就没法省。

也别指望 vibe coding 能替代程序员做复杂系统。它擅长原型和小工具，碰到复杂业务逻辑、大规模性能、硬性安全要求，还是得人来收尾。

多少钱

第一个 App 真不贵。Lovable 免费档或 25 美元 / 月那一档，加 Supabase 0 到 25 美元 / 月（看流量），再加一年 12 美元的域名，满打满算第一个月花的比新加坡一顿双人晚餐还少。

现在就动手

挑一个你每周都做一遍的事，这个周末把它做成你的第一个 vibe coding 作品。表单类工具最稳：记账、读书清单、带邮件通知的联系表单。单个数据类型、单条用户流程，最适合新手。
