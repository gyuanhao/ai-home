## 环境踩坑（Git Bash + Windows Node）
- `cat > /tmp/x.js <<'EOF'` 在本环境有两个坑：① `/tmp` 被 MSYS 转成 `C:\tmp` 导致 node 找不到文件；② heredoc 仍会吞掉反斜杠转义，正则里的 `\\.` 变成 `\.` 引发 SyntaxError。
- 正确做法：用 Write 工具把校验脚本写到工作区根目录（相对路径），再 `node _chk_tmp.js` 执行，跑完 `rm -f` 清理。
