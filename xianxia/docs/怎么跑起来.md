# 怎么跑起来看效果（零基础）

## 起本地服务器（每次看效果都要做）
1. 在 `aihome-game` 文件夹打开命令行
2. 运行：`python -m http.server 8080`
3. 浏览器打开：`http://localhost:8080`

> 全程不上线，只在你自己电脑看。定稿后才部署。

## 怎么玩
- 主菜单点「开始闯荡」进世界地图
- **点地面走动**（暗黑式：点哪走哪）
- 地面有**发光脚印**指引最近未访地点，可跟可不跟
- 走近蓝色地点（万象阁）自动进入，右侧滑出内容面板看模型卡
- 蓝色地点变**青绿** = 已访问（记在你浏览器里，下次还在）
- 点面板「全屏」读长内容，「关闭」返回地图
- 论剑台 / 秘籍阁 / 藏经阁是占位，走近会提示「待开发」

## 怎么改内容（不用动代码逻辑）
- 改地点（加 / 删 / 位置）：`src/data/mapConfig.js`
- 改模型卡内容：`src/data/models.js`
- 改颜色 / 速度 / 画布：`src/config.js`

## 怎么重置存档（重新体验）
浏览器控制台（F12）输入：
```
AIHome.SaveSystem.clear()
```
然后刷新页面。
