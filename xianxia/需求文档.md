## 一、项目概述
把 AI之家网站重构为仙侠网页游戏风格的交互体验：玩家在世界地图上走动，进入各"地点"触发原网站内容（模型库 / 对比 / 技能包 / 博客 / 新闻 等）。技术栈 HTML + JavaScript + Phaser 3，浏览器运行，全程本地开发、定稿后部署。

## 四、调研记录（逐轮）

### 第一轮：整体体验形态
混合（导航 + 轻引导）。需做轻量引导系统，不必做完整主线剧情。

### 第二轮：视觉调性 + 美术来源
像素复古 + AI 生成。瓦片 / 精灵 / UI 全像素风 AI 生成，统一观感、成本 0。

### 第三轮：世界地图布局 + 玩家移动
网状自由探索 + 点击移动。暗黑式点哪走哪；网状易迷路 → 轻引导做成推荐路线地面标记 + 接近地点提示气泡。

### 第四轮：内容面板呈现 + 玩家角色
侧边面板 + 纯代步工具。长内容在侧边面板内加"展开全屏"按钮兼顾阅读；玩家无属性无成长，开发最快。

### 第五轮：轻引导具体形态 + 音频
地面路径标记 + 默认静音可开。地上发光脚印指引、低调不打扰，配合"已访/未访"标记；默认静音不扰民，提供音频开关。

### 第六轮：进度与存档 + 性能与加载策略
记已访地点 + 分场景加载。
**衍生含义**：① localStorage 记去过哪，已访地点标记 / 不再弹引导，提升体验 ② 分场景加载省首屏等待；像素风量小，分场景主要省首屏，实现稍复杂但可控。

## 五、综合设计小结（一句话看全貌）
仙侠**像素风网状地图**，**点击移动**暗黑式走动，**地面发光脚印**轻引导防迷路，进地点弹**侧边面板**看内容（长内容可一键全屏），**纯代步无属性**角色，**localStorage 记已访地点**，**分场景加载**省首屏，**默认静音可开音效**，SEO **双轨**注入结构化数据保引流。
