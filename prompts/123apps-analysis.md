**核心模式：123apps.com 是"导航枢纽"，真正干活的是各子域名上的独立工具。**

## 三、首页设计

123apps 首页极度简洁：
- **无大段文案**：没有hero section的营销话术，只有分类标题 + 工具卡片网格
- **卡片设计**：每个工具 = 一个带图标的矩形方块，点击直达对应子站的工具页
- **分类标签**：视频/音频/PDF/转换器 四个顶部分类，展开后显示该分类下的所有工具
- **无页脚装饰**：footer 只有版权 + 隐私/退款/定价/帮助/联系我们 + 语言切换

## 四、工具详情页设计（以视频编辑器为例）

从截图观察到的工具页结构：

```
顶部导航
├── Logo/返回首页
├── 工具栏菜单（视频/音频/PDF/转换器/解压器）
├── 定价 / 登录 / 语言
└── 工具名称面包屑

主编辑区
├── 上传区域（拖拽或选择文件）
├── 时间轴/轨道
├── 预览窗口
└── 导出按钮（右上角）

侧边栏/控制面板
├── 裁剪、旋转、调整大小等操作
└── 参数设置

页脚：同首页
```

关键发现：
1. **工具即页面**：用户落地页直接就是工具——上传→编辑→导出，零废话
2. **"保存"→"导出"**：改名以匹配专业软件术语（Premiere/Final Cut 都用"导出"）
3. **桌面优先**：部分高级功能（如去水印）明确标注"仅桌面端可用"
4. **跨域名无缝**：切换工具可能跳转到完全不同的域名，但对用户来说是透明的

## 五、定价页面

两档定价，极简对比：

| | Free | Premium |
|---|---|---|
| 日文件数 | 5 | 无限 |
| 最大文件 | 500 MB | 4 GB |
| 处理速度 | 慢 | 快 |
| 文件存储 | 有限 | 优先 |
| 广告 | 有 | 无 |
| 价格 | SGD 0 | SGD 6.90/月 或 SGD 64/年 |

关键信号：
- **年付折扣约 23%**（月付 ×12 = SGD 82.80，年付 SGD 64）
- **没有任何中间档位**——要么免费，要么全部解锁，减少决策疲劳
- 定价页本身也极其简洁，一行比较表就够了

## 六、帮助/FAQ 页面

非常有参考价值的结构：

- **按主题分组**：账单与账号 / 故障排查
- **锚点导航**：每个问题一个锚点，目录在最上面
- **问题粒度极细**：不是"付款问题"，而是"付款被拒绝了怎么办""被扣费两次了怎么办""不小心买了年付怎么办"
- **操作步骤编号**：每步清晰可执行
- **多语言全量覆盖**：CN站帮助也是全中文的

## 七、对 AI之家 的借鉴意义（按落地优先级排序）

### 🔴 立即可做（高投入产出比）

#### 1. 首页：减少啰嗦，放大"工具感"
当前首页 hero 区"帮你省掉搜评测的时间"可以保留，但下方的介绍文字太多。参考 123apps，可以改为：
- **每个品类用一个醒目的卡片**（带图标 + 品类名 + 模型数量），替代现在的文字列表
- **直接在首页嵌入"热门模型快速卡片"区**（已有，但可以更突出）
- 一句话：让用户 3 秒内找到想了解的品类，而不是先读一段介绍

#### 2. 面包屑导航
所有子页面（模型详情页、对比页）加面包屑：
```
首页 > 模型库 > 语言模型 > DeepSeek
```
提升 SEO（结构化数据）和用户导航体验。

#### 3. 详情页 SEO 矩阵扩展
123apps 的每个工具都是一个独立的可搜索页面。我们的详情页目前只有 8 个，应该扩展到**所有 32 个模型**，每个都是独立的长尾关键词着陆页。注意：生成脚本已经写好了（`generate_model_pages.py`），只需修改提取逻辑让它覆盖全部模型。

### 🟡 中期考虑（需要一定工作量）

#### 4. "工具即页面"——AI之家版
123apps 用户落地就是工具。我们的"工具"是什么？
- **不是模型本身**（我们不做API代理）
- **是对比和推荐**——这是我们的核心功能

可以做一个**首页直达对比工具**的设计：用户在首页直接选 2-3 个模型 → 跳转对比页 → 看横向对比 → 点击直达模型官网。减少中间点击次数。

#### 5. 帮助/FAQ 页面
目前我们没有。可以做一个轻量的 FAQ：
- 我是新手，怎么选？
- ChatGPT 和 DeepSeek 有什么区别？
- 免费和付费怎么选？
- 为什么推荐国内模型？（这是中文站的核心价值）

#### 6. 定价页的借鉴——未来变现时
当 AI之家进入变现阶段，参考 123apps 的两档制：
- 免费：所有模型信息可查，但有广告
- Premium：去广告 + 高级对比功能 + 更新提醒
- 不搞中间档，减少决策成本

### 🟢 暂不需要

#### 7. 多域名架构
123apps 用多域名是因为各子站是完全独立的产品（视频编辑 vs PDF转换 技术栈不同）。AI之家不需要——所有页面共享同一套数据（`main.js`），单域名是最优解。

#### 8. 文件上传/处理
AI之家不做工具类产品的文件处理功能，这部分不适用。

## 八、核心启示

123apps 最值钱的经验就一句话：

> **让用户在 5 秒内明白"这里能帮我干什么"，然后 1 步到达使用场景。**

映射到 AI之家就是：
- 用户想知道"我该用哪个AI"→ 看到模型卡片 → 点进去看对比 → 点链接直达 → **完事**
- 整个流程中间不应该有多余的阅读负担

我们现在的网站，首页文案偏多、模型卡片不够突出、详情页只有 8 个、缺少面包屑——这些都是可以在不改变架构的情况下快速改进的。
