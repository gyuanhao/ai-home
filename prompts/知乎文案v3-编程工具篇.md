## 正文

上次写完那个AI工具对比站之后，后台好几个人问编程工具的事。

说实话，我主业是财务研究分析，代码纯属自学保命。但这两年AI编程工具卷得离谱，我一个半吊子都被卷进去了——因为现在不会用AI写代码，在工作里真的吃亏。

我自己日常用的就两个：WorkBuddy 和 Claude Code。其余几个是朋友在用、或者技术圈子里讨论得多的，我把听来的也一起说说。不端水，有偏见就有偏见。

---

先说 WorkBuddy。

这个工具知道的人不多，但它是我目前用的主力。简单说，它不是一个纯粹的编程工具——更像一个全栈助手，能写代码、能跑命令、能读写文件、能部署。对我来说最大的价值是"一站式"：我不用在IDE、终端、浏览器之间来回切，大部分事情在WorkBuddy里就搞定了。

实际场景大概是这样的：我想做一个数据处理脚本，不需要自己开VS Code新建文件夹配环境。直接跟它说"帮我写一个分析这张Excel表的Python脚本"，它会自己建文件、写代码、装依赖、跑起来、报错了自己改。我在旁边看着就行——偶尔说一句"这个逻辑不对"或者"加个图表"。

缺点也有。它不是传统IDE，如果你习惯在编辑器里手敲代码，会不适应这个模式。而且它目前对超大项目（比如几万行的代码库）的掌控力还不够，更适合中小项目或者独立任务。

但对我来说，这就够了。打工人的真实场景不是"写一个完美的架构"，是"三小时后要给老板交东西"。

---

再说 Claude Code。

Claude Code 和 WorkBuddy 是完全不同的东西。它是一个终端 Agent，你装好之后在命令行里调用，它能直接读你的项目结构、理解代码、然后帮你改。

我用它做过什么？上个月有个财务数据处理项目，几百个文件、中间一堆冗余脚本。我把项目路径丢给Claude Code，让它帮我理一下依赖关系、删掉没用的文件——它真的做完了，而且没删错。那一刻我确实有点震惊。

但它的脾气也很明显。第一，贵。按token计费，不是按月订阅。我跑了两次大任务，账单跳得比心跳快。第二，不稳。有时候你给它一个任务，它改了代码但引入了新的小bug，你要再跟它来回几次。有人说它适合"有明确目标的小任务"，不太适合"帮我重构整个系统"。

我自己的感受是：Claude Code 像是一个技术很强但不爱沟通的同事。你交代清楚，它能干得漂亮。你如果含糊，它也能跑偏。

---

剩下几个我没深度用过，但圈子里讨论得太多，耳朵都起茧了。按我听到的说说。

DeepSeek V4，圈内最大的评价是"免费的离谱"。今年4月V4系列发布之后，好几个朋友直接弃了付费工具转投DS。V4-Pro编程能力确实硬，推理链能一步步拆问题，不是那种丢一段代码就走人的风格。但它的短板也很统一：没有IDE集成，你得复制粘贴。另一个朋友的说法是"DeepSeek当编程老师特别好，当编程搭档差点意思"——因为它只能给你代码，不能帮你改项目。

Cursor，朋友圈里的评价很两极。有人说它是"2026年最好的AI IDE，没有之一"，TAB补全的准确率高到让人怀疑它在读你脑子。但另一边也有人说它"对新手不友好"——补全太激进了，看不懂代码的人容易被误导，接受一个看起来对但实际有bug的建议。价格是$20/月，不是谁都愿意掏。而且最近有人在讨论Cursor在国内的模型限制问题，有人因为这个转去了Windsurf。

GitHub Copilot，我听到的最多一句话是"公司花钱用，自己掏钱不买"。不是说它不好，而是它的核心价值在GitHub生态整合。如果你用GitHub做项目管理、CI/CD那一套，确实无缝。但单论补全体验，很多人说不如Cursor聪明。Agent模式今年开始推，能自动修bug、跑测试，但稳定性和实际效果还有待考验。有人在知乎上说"我用它修一个SQL脚本，跑是能跑了，但它把索引建议顺手删了"——大概就是这种感觉。

通义灵码，阿里系的朋友用得最多。免费，中文注释写得特别自然，不是那种机翻味。有人说对Java和Go后端开发特别友好，因为对阿里系组件的理解很深。但也有朋友说它的补全速度比Cursor慢半拍，而且IDE集成目前主推JetBrains和VS Code，其他编辑器支持一般。整体评价：对新手和阿里云生态用户最友好，是企业级应用的好选择，但极致效率党可能会换别的。

Windsurf，听朋友说是Cursor的轻量替代。Cursor在国内遭模型限制之后，有些人转去了Windsurf。优点是上下文理解做得好，能比较准确地感知整个项目结构。价格也便宜一些。但Agent能力和补全体验，圈子里普遍认为比Cursor还差一口气。有人说"如果只是想要AI辅助写代码，Windsurf够用。如果想要最强Agent帮你干活，还是要去Cursor或Claude Code。"

---

最后说个很个人的观察。

我是在香港上班的打工人，做财务研究分析。去年用AI写代码还是个"加分项"，今年已经变成"你不会用AI写代码就别干这行了"的感觉。同事在讨论的不是"要不要用"，而是"用哪个""怎么用更省"。

这也是我做那个对比站的原因——AI家AI户（myaishome.com），我把35个AI工具的价格、功能、编程排名、中文体验全整理好了，编程类专门有代码模型筛选页。不是权威评测，就是自己用过或者听圈子里反复讨论之后，觉得值得整理的东西。数据都标了来源和更新日期，看一眼就能决定用哪个。

---

总结一句：

WorkBuddy 是我的日常主力，一站式把事做完。Claude Code 是高级武器，技术很强但花钱也快。

如果你预算为零，DeepSeek V4 + 通义灵码，圈子里公认的免费组合。如果要效率极致，Cursor + Claude 模型是目前讨论热度最高的配置。Copilot 给重度 GitHub 用户，Windsurf 是 Cursor 受限时的备选。

不用纠结，先免费的用起来，不够再升。
